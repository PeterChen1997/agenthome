# AgentHome 功能清单（信息架构 v1）

> 2026-11-05。先把"有哪些功能、各在哪个界面、做到哪一步"摆清楚，再谈视觉。状态：✅ P0 已有 · 🔜 P1 · ⏳ P2 · 💤 P3。

## 0. 一句话

本机所有 AI agent 的家：**看额度 · 看消耗 · 翻旧账**。三件事对应三个一级入口，菜单栏是它们的常驻缩影。

## 1. 信息架构

```
菜单栏常驻（额度 + 今日 + 最近）
└── 主窗口
    ├── 仪表盘      看额度、看消耗
    ├── 归档        翻旧账：来源 / 项目 / 视图 → 会话列表 → 会话详情
    ├── 搜索 ⌘K     跨一切的入口（会话、消息、工具输出、项目、命令）
    └── 设置        来源与 Provider、归档位置、合规开关、主题、hook 安装
```

## 4. 视觉上需要被"看见"的东西（给设计方向用）

- **三种状态必须一眼分开**：原件还在 / 仅归档存在 / 即将被清理。
- **额度的紧迫感**要靠形状和颜色同时传达，不能只靠数字。
- **Trace 行是最高频的阅读单元**，密度和折叠手感决定产品好不好用。
- **来源身份**（Claude / Codex / Gemini）贯穿所有界面，需要一套稳定的标识，不只是一个色点。
- **数字很多**（token、成本、百分比、时间），需要等宽与对齐规则。
- **token 用量是 M 级的大数**，要有稳定的单位规则（k / M / B）与分层展示（输入 / 输出 / 缓存），不能一个总数糊过去。
- **"还有多少、什么时候没"是核心焦虑**：窗口重置倒计时、credits 余额与过期、订阅周期，这三类时间要同屏可见。
