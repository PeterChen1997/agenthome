## 结构

```
crates/core   agenthome-core：model / store(rusqlite + FTS5) / providers/claude_code / ingest / paths
crates/cli    agenthome：scan / sessions / show / stats
crates/app    agenthome-app：gpui-kit 三栏（Sidebar 项目 / uniform_list 会话 / MessageScroller 详情）+ SqliteDataSource
script/bundle-dev.sh   把 debug 二进制包成 target/AgentHome.app（开发用，正式打包走 cargo-packager）
rust-toolchain.toml    钉 1.99.1（gpui-pre 0.3.11 需要 ≥ 1.97，本机默认 stable 是 1.96）
```

常用命令：

```bash
cargo run -p agenthome-cli --release -- scan        # 扫描 ~/.claude/projects 到 ~/AgentHome/index/agenthome.db
cargo build -p agenthome-app && ./script/bundle-dev.sh && open target/AgentHome.app
cargo run -p agenthome-app -- --mock                  # 不依赖索引库的 mock 数据
```

## 真实数据才暴露的问题（已处理）

1. **uuid 不唯一**：fork / resume 会把历史行复制进新文件，resume 也会在同一文件重写一段历史。处理：messages 主键改为 (session_id, id)，同文件按 uuid 去重，先到者为准，计数进 `ignored_records["duplicate-uuid"]`（本机 20 条）。
2. **子代理 agentId 跨父会话重复**（父会话 fork 时子代理文件一起被复制）。处理：子代理 `native_id = "<父uuid>/<agentId>"`。
3. 非对话记录种类比调研文档多得多（本机出现 24 种 type，如 `atis-latch`、`frame-link`、`last-prompt`、`bridge-session`），全部计数不入库，不静默丢。
