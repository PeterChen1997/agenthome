# 视觉方向头脑风暴（2026-11-05）

> 背景：v1 设计稿被评价"太普通"。用生图模型（gpt-image-2.5-flare）对同一个产品出了 6 个差异化方向，用来选方向，不是定稿。图里的文案、数字、品牌名都是模型自己编的，只看气质。
> 功能依据见 `docs/03-功能清单.md` 第 4 节："视觉上需要被看见的东西"。

| # | 方向 | 一句话 | 最擅长表达 | 风险 | gpui-kit 落地难度 |
|---|---|---|---|---|---|
| 01 | 仪表舱 Instrument Deck | 航空座舱 × 终端，石墨黑底青/琥珀读数 | 密度、额度表盘、Trace 状态灯 | 容易滑向"赛博仪表盘"套路，长时间阅读对话偏累 | 中：深色主题 + 自绘环形表盘 |
| 02 | 档案馆 Archive Room | 图书馆卡片目录，米纸、衬线、橡皮章 | **三种归档状态（原件在 / 仅归档 / 即将清理）用印章一眼分开**，归档的身份感最强 | 纸纹理不能照搬，要压成平面色；数字密集时衬线不利对齐 | 中低：主题色 + 思源宋体 + 印章样式标签，纹理全去掉 |
| 03 | 居所平面图 Floor Plan | 等轴测房子，每个 agent 一间房 | "家"的隐喻、来源身份 | 它本质是一张插画而不是界面系统；图里还把产品画成了聊天客户端（我们不聊天） | 高：插画是独立资产；只适合做空态 / 图标 / 启动页 |
| 04 | 电表 Utility Meter | 工业电表：翻页计数器、指针表、七段数码管 | **M 级 token 累计数、额度指针、重置倒计时、credits 过期**，正是新补的需求 | 全拟物太重，三栏归档页没法套 | 中：压扁成"平面拟物"（等宽大数字、半圆仪表、倒计时），不画金属螺丝 |
| 05 | 编辑部账簿 Editorial Ledger | 报纸版式，黑白大数字，细线分栏，朱红警示 | 仪表盘的头条数字、趋势图标注、"今日"叙事 | 归档三栏在这个风格下会单调；大量小字需要克制 | 低：纯排版，一套字体就成 |
| 06 | 像素栖息地 Pixel Habitat | 小屋里住着三只像素小动物，体力条 = 额度 | 趣味、"养"的感觉、额度紧迫感很直观 | 开发者工具里显得玩具化；像素资产要画 | 中：像素图只占一个 widget，其余是常规深色 UI |

## 我的判断

单选一个都会有一块短板：02 / 05 讲不好仪表盘的"物理感"，01 / 04 讲不好归档的"档案感"。

**推荐组合：02 档案馆 + 04 电表（压扁）。**

- 全局：米纸底、墨黑字、一个信号橙（警示 / 倒计时），中文用思源宋体做标题、等宽做数字。
- 归档三栏：卡片目录 + 印章式状态标签（原件在 / 仅归档 / 6 天后清理），Trace 行用收据式等宽排版。
- 仪表盘与菜单栏：翻页计数器风格的 M 级 token 大数、半圆指针式额度表、七段风格倒计时（重置 / credits 过期）、地震仪式 token 趋势条。
- 来源身份：每个 agent 一枚"印章"（Claude 赭红 / Codex 绿 / Gemini 蓝），贯穿所有界面。

**备选：05 编辑部账簿整套。** 最便宜、最统一、最不像别的工具，代价是归档页要靠排版节奏撑住，Trace 行需要单独设计。

**03 和 06 的可取之处**：03 的房子可以作为 App 图标与首次启动空态；06 的"体力条 = 额度"隐喻可以借到菜单栏弹窗里。
