# Code of Conduct / 行为准则

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. A Chinese translation is available at <https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/>.

本项目采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/) 作为行为准则。

## In short / 简述

- Be respectful and inclusive. Harassment, insults, and personal or political attacks are not tolerated.
- Give and accept constructive feedback gracefully; focus on what is best for the community.
- Do not publish others' private information without explicit permission.

- 尊重与包容他人，不接受骚扰、侮辱以及人身或政治攻击。
- 善意地给出与接受建设性反馈，以社区整体利益为先。
- 未经明确许可，不公开他人的私人信息。

These rules apply in all project spaces (issues, pull requests, discussions) and when representing the project in public.

以上规则适用于项目的所有空间（issue、PR、讨论区），以及公开代表本项目的场合。

## Enforcement / 执行

Report unacceptable behavior privately to the maintainer through the contact listed on the maintainer's GitHub profile, or through GitHub's **Report content** feature. All reports are reviewed and kept confidential. Maintainers may remove, edit or reject contributions, and temporarily or permanently ban contributors whose behavior violates this code, following the enforcement guidelines of Contributor Covenant 2.1.

如遇不当行为，请通过维护者 GitHub 主页上的联系方式私下报告，或使用 GitHub 的 **Report content** 功能。所有报告都会被审阅并保密。维护者可依据 Contributor Covenant 2.1 的执行指南，移除、编辑或拒绝相关贡献，并临时或永久禁止违规者参与。
